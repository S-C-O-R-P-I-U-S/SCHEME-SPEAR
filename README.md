# SCHEME-SPEAR
SCHEME SPEAR is an end-to-end welfare engine featuring sub-50ms Gemini AI matching across 3,500+ Central &amp; State schemes, an uploadable Document Locker (Aadhaar, Caste/Income certs), EMI subsidy simulation, geolocation bank discovery, and a native application portal for direct in-website scheme selection, submission, and live tracking.
